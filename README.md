# pixel-sort — 画像のピクセルを並び替える

画像を選ぶと、ピクセルを明るさや色で並び替えて変換します。画像は端末の中だけで処理します。

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/pixel-sort/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

1. 画像を選ぶ（またはドラッグ＆ドロップ）。大きい画像は長辺 1024px 程度に縮めてから処理する。
2. 並び替えのルール（明るさ・R・G・B・色相）と昇順／降順を選ぶと、右側の画像が変わる。
3. 「PNG を保存」でダウンロードする。画像はブラウザの中だけで処理し、どこにも送らない。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
```
